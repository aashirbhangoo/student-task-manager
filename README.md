# Student Task Manager

A simple web application developed as a pair-based Git and GitHub collaborative assignment.

The *Student Task Manager* allows users to add tasks, display tasks, mark tasks as completed, delete tasks, and search for tasks.

The main purpose of this project is to demonstrate a real collaborative software-development workflow using Git and GitHub.

## Project Description

Student Task Manager is a simple web-based application designed to help students manage their daily tasks.

Users can:

- Add new tasks
- Display tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Search for tasks

The project is also used to demonstrate collaborative Git and GitHub practices such as branches, commits, pull requests, code reviews, merges, merge conflicts, Git recovery commands, tags, and releases.

---

## Features

### Task Management

- Add a new task
- Display all tasks
- Mark a task as completed
- Undo a completed task
- Delete a task

### Search

- Search tasks by their text
- Display matching tasks while typing

### Responsive Design

- Mobile-friendly layout
- Responsive input fields
- Responsive buttons and task items
- No unnecessary horizontal scrolling
